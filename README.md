# JONASXZB

## $5 Quick Website Fix / UI Polish

I take tiny, tightly scoped website fixes for indie hackers, students, small website owners, GitHub project maintainers, landing page makers, and small SaaS builders.

Good fit for a $5 first fix:

- HTML/CSS layout bug
- React component UI issue
- Tailwind spacing or responsiveness issue
- mobile viewport problem
- button, card, navbar, or section polish
- README quick-start improvement
- small landing page copy improvement

What is included:

- one small issue
- one minimal fix or polish pass
- desktop/mobile check for the changed area
- changed files, patch, or pull request
- short before/after notes

What is not included:

- full website redesigns
- complex backend work
- fake engagement, reviews, votes, follows, installs, or spam
- private keys, seed phrases, bank details, account logins, or OTP handling
- large unpaid trials

## How To Request A Fix

Open a request here:

- [New $5 website fix request](https://github.com/JONASXZB/JONASXZB/issues/new?template=quick-website-fix.yml)

Please include:

1. Website or repo URL
2. Exact issue
3. Screenshot or screen recording
4. Tech stack
5. Expected result
6. Deadline
7. Preferred payment network

Crypto payment is preferred after scope confirmation. USDC on Base/Polygon or USDT TRC20 is preferred for small payments because fees are usually lower. Never send private keys, seed phrases, bank details, exchange logins, or OTP codes.
